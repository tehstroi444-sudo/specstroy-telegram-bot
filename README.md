# Telegram-бот «СпецСтрой» на Python

Бот работает через long polling, поэтому Google Apps Script и webhook больше не нужны.

## Что умеет

- пошагово принимает ежедневный отчёт;
- показывает кнопки выбора техники, вида работы, ставки и оплаты;
- считает часы и сумму;
- записывает отчёт в Google Таблицу;
- поддерживает команды `/start`, `/new`, `/cancel`.

## 1. Подготовьте Google Cloud

1. Откройте Google Cloud Console.
2. Создайте новый проект.
3. В разделе **API и сервисы → Библиотека** включите:
   - Google Sheets API;
   - Google Drive API.
4. Перейдите **API и сервисы → Учетные данные**.
5. Нажмите **Создать учетные данные → Сервисный аккаунт**.
6. Создайте сервисный аккаунт.
7. Откройте его → **Ключи → Добавить ключ → Создать новый ключ → JSON**.
8. Скачанный файл переименуйте в:

```text
service_account.json
```

9. Откройте файл и найдите поле:

```json
"client_email": "имя@проект.iam.gserviceaccount.com"
```

10. Откройте Google Таблицу и дайте этому email права **Редактор**.

## 2. Запуск на Windows

Установите Python 3.12 или новее.

Откройте папку проекта в командной строке:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Откройте `.env` и вставьте токен BotFather:

```env
BOT_TOKEN=123456789:AA...
```

Положите `service_account.json` рядом с `bot.py`.

Запустите:

```bat
python bot.py
```

В консоли появится:

```text
Запуск Telegram-бота...
```

Теперь отправьте боту `/start`.

## 3. Постоянная работа

Пока окно командной строки открыто, бот работает. Для постоянной работы разместите проект на сервере или облачном хостинге.

Для хостинга секреты задаются переменными окружения:

- `BOT_TOKEN`
- `SPREADSHEET_ID`
- `SHEET_NAME`
- `GOOGLE_SERVICE_ACCOUNT_JSON`

В `GOOGLE_SERVICE_ACCOUNT_JSON` вставляется весь JSON сервисного аккаунта одной строкой. Сам файл JSON в GitHub загружать нельзя.

## Проверка Google Таблицы

По умолчанию используется таблица:

```text
1LLEE79yZpd2o-vBXDz0Z_uHx97lgR_Eo
```

и лист:

```text
Отчеты
```

Если листа нет, бот создаст его автоматически.

## Важная безопасность

Не публикуйте:

- токен Telegram;
- `.env`;
- `service_account.json`;
- значение `GOOGLE_SERVICE_ACCOUNT_JSON`.

При утечке токена создайте новый через BotFather.
